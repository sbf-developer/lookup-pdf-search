# Lookup

A fast desktop app for searching a textbook and slide PDFs during an exam.

Double-click `run.bat`. The first launch installs what it needs. After that it opens straight away.

Add PDFs with **Add PDFs**, or drop them on the window. The last files reopen next time.

## Search

Type in the bar. Results update as you type. Arrow keys move through hits: the page jumps to the words, and the right panel shows the hit plus the sentences that follow it.

**Broad** is the default. It also finds close wording, so `data mining` matches `data mine`, light typos, and words that sound similar.

**Exact** finds the words in order, as written. Ctrl+B switches mode.

## Keys

- ↑ ↓ move through hits
- Ctrl+O add PDFs
- Ctrl+F search
- Ctrl+B Exact / Broad
- Ctrl+0 fit the page
- Ctrl+scroll zoom

Scanned PDFs with no text layer cannot be searched. The file chip says “no text” when that happens.
